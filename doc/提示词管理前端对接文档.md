# 提示词管理 & 会话配置改造 — 前端对接文档

## 变更概述

| 变更 | 说明 |
|------|------|
| **新增模块** | 提示词管理（CRUD），菜单位于 AI管理 → 提示词管理 |
| **修改模块** | 会话配置管理改造：新增 `config_key` 字段 + 提示词关联多选 |
| **后端端点** | `xinling-ai` 模块，`/ai/prompt/*` 和 `/ai/session/*` |

## 一、提示词管理页面

### 1.1 页面路由

```
路径: /ai/prompt/index
菜单: AI管理 (2210) → 提示词管理 (2260)
权限: ai:prompt:list
```

### 1.2 API 接口

#### 1.2.1 列表查询

```
GET /ai/prompt/list
权限: ai:prompt:list

参数:
  promptName: string (模糊搜索)
  modelId: number (按模型筛选)
  status: string (0=正常 1=停用)
  pageNum: number
  pageSize: number

响应:
{
  "code": 200,
  "msg": "查询成功",
  "total": 10,
  "rows": [
    {
      "promptId": 1,
      "promptName": "小灵人设提示词",
      "content": "你叫「小灵」...",
      "modelId": null,
      "modelName": "通用",
      "modelCode": null,
      "status": "0",
      "sortOrder": 1,
      "remark": "移动端小灵数字人的角色人设",
      "createTime": "2026-07-14 10:00:00"
    }
  ]
}
```

#### 1.2.2 查询详情

```
GET /ai/prompt/{promptId}
权限: ai:prompt:query
```

#### 1.2.3 新增

```
POST /ai/prompt
权限: ai:prompt:add

Body:
{
  "promptName": "新提示词",
  "content": "提示词内容，支持{currentDate}等变量",
  "modelId": null,         // null=通用, 有值=仅该模型可用
  "status": "0",
  "sortOrder": 1,
  "remark": "备注说明"
}
```

#### 1.2.4 修改

```
PUT /ai/prompt
权限: ai:prompt:edit

Body: (同新增，加上 promptId)
```

#### 1.2.5 删除

```
DELETE /ai/prompt/{promptIds}
权限: ai:prompt:remove
示例: DELETE /ai/prompt/1,2,3
```

#### 1.2.6 获取所有启用的提示词（下拉选择用）

```
GET /ai/prompt/enabledList
权限: 所有登录用户
```

### 1.3 页面字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| promptName | 文本输入框 | 是 | 提示词名称，唯一 |
| content | 文本域 / 富文本 | 是 | 提示词内容，支持模板变量 |
| modelId | 下拉选择 | 否 | 适配模型，空=通用 |
| status | 单选(switch) | 否 | 状态：0正常 1停用 |
| sortOrder | 数字输入框 | 否 | 排序（多个提示词时的拼接顺序） |
| remark | 文本输入框 | 否 | 备注 |

### 1.4 列表列

| 列 | 宽度 | 说明 |
|----|------|------|
| 提示词ID | 80px | |
| 提示词名称 | 200px | |
| 模型适配 | 150px | 显示模型名称，通用显示"所有模型" |
| 排序 | 80px | |
| 状态 | 80px | 状态tag |
| 备注 | auto | 截断显示 |
| 创建时间 | 180px | |
| 操作 | 200px | 修改/删除 |

### 1.5 注意事项

- 删除提示词时需确认没有会话配置正在关联该提示词（后端会软限制，前端提示）
- content 字段可能很长，编辑时建议用大文本框或弹窗编辑
- modelId 为空表示"通用"，不是"不限制"

## 二、会话配置管理改造

### 2.1 页面修改

**原有页面**: `ai/session/index`
**新增功能**: config_key 字段 + 提示词多选

#### 2.1.1 新增/编辑表单新增字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| configKey | 文本输入框 | 否 | 配置标识键（platform/mobile/ontology/nl2sql），一般不手动填写，由种子数据生成 |
| prompts | 多选下拉框 | 否 | 选择关联的提示词，从 `/ai/prompt/enabledList` 获取选项 |

#### 2.1.2 新增/编辑 API 变更

```
PUT /ai/session   (修改)
POST /ai/session  (新增)

Body 新增字段:
{
  ...原有字段,
  "configKey": "platform",     // 可选
  "promptIds": [1, 2, 3]       // 关联的提示词ID数组（新增！）
}
```

#### 2.1.3 详情 API 变更

```
GET /ai/session/{configId}

响应新增字段:
{
  ...原有字段,
  "configKey": "platform",
  "prompts": [                  // 关联的提示词列表
    {
      "promptId": 1,
      "promptName": "AI助手通用提示词",
      "content": "你是 XinLing 系统的AI智能助手...",
      "modelId": null,
      "status": "0",
      "sortOrder": 1
    }
  ],
  "promptIds": [1, 2, 3]       // 关联的提示词ID数组
}
```

### 2.2 列表列调整

| 列 | 操作 |
|----|------|
| 现有列 | 保留不变 |
| 配置标识 | **新增**，显示 `config_key` |
| 关联提示词 | **新增**，显示关联提示词数量（如"已关联 2 个"） |

### 2.3 提示词多选组件

```vue
<!-- 建议封装为多选组件 -->
<el-select
  v-model="form.promptIds"
  multiple
  placeholder="请选择关联提示词"
  style="width: 100%"
>
  <el-option
    v-for="item in promptOptions"
    :key="item.promptId"
    :label="item.promptName"
    :value="item.promptId"
  />
</el-select>
```

## 三、种子数据（预置，共4个会话配置+4个提示词）

### 3.1 会话配置

| config_key | config_name | 说明 |
|-----------|-------------|------|
| platform | 平台默认配置 | 管理后台聊天，is_default=1 |
| mobile | 移动端配置 | App用户聊天（小灵） |
| ontology | 本体推理配置 | 本体知识推理 |
| nl2sql | NL2SQL配置 | 自然语言转SQL |

### 3.2 提示词

| prompt_name | 内容来源 | 关联配置 |
|------------|---------|---------|
| AI助手通用提示词 | 通用AI助手人设 | platform, mobile |
| 小灵人设提示词 | 小灵数字人角色 | mobile |
| 本体推理提示词 | 原 ontology-prompt.st | ontology |
| NL2SQL提示词 | 原 system-prompt.st | nl2sql |

### 3.3 前端只读提示

**platform、ontology、nl2sql** 这三个配置属于系统配置，建议在编辑时提示用户"此为系统配置，修改可能导致功能异常"。**mobile** 配置可以自由修改（如更换小灵的人设提示词）。

## 六、开发注意事项

1. **content 字段长度**：提示词内容可能很长（如NL2SQL提示词超过 2000 字），列表显示时建议省略显示
2. **批量删除**：删除提示词时，需先确认没有被任何会话配置关联
3. **启用/停用**：停用提示词后，已有会话不会受影响（ChatMemory 中已注入），但新会话不会加载
4. **编辑时字典**：`sortOrder` 字段建议使用数字输入框，范围 0-999
