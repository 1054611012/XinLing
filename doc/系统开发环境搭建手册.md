# 心灵AI系统开发环境搭建手册

## 1. 项目概述

心灵AI是一套基于Spring Boot 3.x + Vue前后端分离的AI增强企业级管理系统，深度融合了AI技术和可扩展的企业级特性。

### 核心技术栈
- **后端**：Spring Boot 3.5.4, Spring Security, MyBatis, Redis, RabbitMQ/Kafka
- **前端**：Vue 2.x, Element UI
- **AI集成**：LangChain4j, Ollama, DeepSeek, OpenAI
- **数据库**：MySQL 8.x
- **构建工具**：Maven 3.6+, Node.js 14+

## 2. 开发环境要求

### 2.1 硬件要求
- CPU: 4核及以上
- 内存: 16GB RAM（推荐32GB）
- 存储: 至少50GB可用空间

### 2.2 软件要求

| 组件 | 版本要求 | 说明 |
|------|----------|------|
| JDK | 21+ | 推荐使用OpenJDK 21 |
| Maven | 3.6+ | 构建工具 |
| Node.js | 14+ | 前端构建 |
| Redis | 6.0+ | 缓存服务 |
| MySQL | 5.7/8.0 | 数据库 |
| RabbitMQ | 3.8+ | 消息队列（可选） |
| Kafka | 2.8+ | 消息队列（可选） |

## 3. 环境搭建步骤

### 3.1 安装JDK 21

#### macOS安装
```bash
# 使用Homebrew安装
brew install openjdk@21

# 或者手动下载安装后配置环境变量
export JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk-21.jdk/Contents/Home
export PATH=$JAVA_HOME/bin:$PATH
```

#### 验证安装
```bash
java -version
javac -version
```

预期输出：
```
openjdk version "21.0.x" 202x-xx-xx
OpenJDK Runtime Environment (build 21.0.x+...)
OpenJDK 64-Bit Server VM (build 21.0.x+..., mixed mode, sharing)
```

### 3.2 安装Maven

#### macOS安装
```bash
# 使用Homebrew安装
brew install maven

# 验证安装
mvn -version
```

#### 配置settings.xml
在`~/.m2/settings.xml`中配置阿里云镜像：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<settings xmlns="http://maven.apache.org/SETTINGS/1.0.0"
          xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
          xsi:schemaLocation="http://maven.apache.org/SETTINGS/1.0.0 
          http://maven.apache.org/xsd/settings-1.0.0.xsd">
          
  <mirrors>
    <mirror>
      <id>aliyun</id>
      <mirrorOf>central</mirrorOf>
      <name>Aliyun Maven</name>
      <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
  </mirrors>
  
  <profiles>
    <profile>
      <id>jdk-21</id>
      <activation>
        <activeByDefault>true</activeByDefault>
        <jdk>21</jdk>
      </activation>
      <properties>
        <maven.compiler.source>21</maven.compiler.source>
        <maven.compiler.target>21</maven.compiler.target>
        <maven.compiler.release>21</maven.compiler.release>
      </properties>
    </profile>
  </profiles>
</settings>
```

### 4.3 配置数据库

#### 4.3.1 创建数据库
```sql
CREATE DATABASE xinling DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE xinling;
```

#### 4.3.2 导入初始化脚本
```bash
# 执行SQL目录下的初始化脚本
mysql -u root -p xinling < sql/ry_20250522.sql
```

#### 4.3.3 配置数据库连接
修改`xinling-admin/src/main/resources/application-druid.yml`中的数据库配置：

```yaml
spring:
  datasource:
    druid:
      master:
        url: jdbc:mysql://localhost:3306/xinling?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=false&serverTimezone=GMT%2B8&connectTimeout=60000&socketTimeout=60000&allowPublicKeyRetrieval=true
        username: root
        password: your_password
        driver-class-name: com.mysql.cj.jdbc.Driver
```

## 6. 系统配置

### 6.1 AI功能配置

#### 6.1.1 配置AI模型提供商
在`xinling-admin/src/main/resources/application.yml`中配置：

```yaml
ai:
  model:
    provider: ollama  # 可选: ollama, deepseek, openai
    default-model: qwen2.5:3b
    use-local: true

  ollama:
    base-url: http://localhost:11434
    api-key: ollama
    model: qwen2.5:3b
    timeout-seconds: 360

  deepseek:
    base-url: https://api.deepseek.com/v1
    api-key: your-deepseek-api-key
    model: qwen2.5:3b
    timeout-seconds: 360

  openai:
    api-key: your-openai-api-key
    base-url: https://api.openai.com/v1
    model: gpt-4o-mini

  rag:
    knowledge-base-path: /path/to/your/knowledge/base
    max-results: 3
    min-score: 0.5
    chunk-size: 500
    chunk-overlap: 0
```

#### 6.1.2 启动Ollama（如果使用）
```bash
# 下载并安装Ollama
curl -fsSL https://ollama.ai/install.sh | sh

# 启动Ollama服务
ollama serve

# 拉取所需模型
ollama pull qwen2.5:3b
```

### 6.2 消息队列配置

#### 6.2.1 选择消息中间件
在`application.yml`中配置：

```yaml
xinling:
  mq:
    type: rabbitmq  # 可选: rabbitmq 或 kafka
```

#### 6.2.2 RabbitMQ配置
```yaml
spring:
  rabbitmq:
    host: 127.0.0.1
    port: 5672
    username: guest
    password: guest
    virtual-host: /
    publisher-confirm-type: correlated
    publisher-returns: true
    template:
      mandatory: true
    listener:
      simple:
        acknowledge-mode: manual
        prefetch: 1
```

#### 6.2.3 Kafka配置
```yaml
spring:
  kafka:
    bootstrap-servers: localhost:9092
    consumer:
      group-id: chat_group
      auto-offset-reset: earliest
      key-deserializer: org.apache.kafka.common.serialization.StringDeserializer
      value-deserializer: org.springframework.kafka.support.serializer.JsonDeserializer
      properties:
        spring.json.trusted.packages: "com.xinling.mq.dto"
    producer:
      key-serializer: org.apache.kafka.common.serialization.StringSerializer
      value-serializer: org.springframework.kafka.support.serializer.JsonSerializer
      properties:
        spring.json.trusted.packages: "com.xinling.mq.dto"
    listener:
      ack-mode: manual_immediate
```

## 9. 常见问题解决

### 9.1 Maven构建问题
```bash
# 清理并重新构建
mvn clean compile -U

# 如果遇到编码问题
mvn clean compile -Dfile.encoding=UTF-8

# 如果遇到网络问题
mvn clean compile -Dmaven.wagon.http.ssl.insecure=true -Dmaven.wagon.http.ssl.allowall=true
```

### 9.2 端口冲突解决
如果端口8080已被占用，可在`application.yml`中修改：
```yaml
server:
  port: 8081  # 修改为其他可用端口
```

### 9.3 数据库连接问题
确保MySQL服务正常运行，并检查：
- 数据库是否创建
- 用户名密码是否正确
- 数据库连接URL是否正确
- MySQL是否允许远程连接

### 9.4 Redis连接问题
- 确认Redis服务已启动
- 检查Redis配置文件中的bind地址
- 确认端口6379未被防火墙阻止

## 10. 开发调试

### 10.1 IDE配置（IntelliJ IDEA）

#### 10.1.1 Maven配置
1. File → Settings → Build → Build Tools → Maven
2. 设置Maven home directory为Maven安装路径
3. 设置User settings file为`~/.m2/settings.xml`
4. 设置Local repository为本地仓库路径

#### 10.1.2 JDK配置
1. File → Project Structure → Project
2. 设置Project SDK为JDK 21
3. 设置Project language level为21

#### 10.1.3 运行配置
1. Run → Edit Configurations
2. 添加Spring Boot配置
3. 选择XinLingApplication作为Main class
4. 设置VM options（如有需要）

### 10.2 热部署配置
在`pom.xml`中确保包含：
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-devtools</artifactId>
    <scope>runtime</scope>
    <optional>true</optional>
</dependency>
```

### 10.3 日志配置
修改`application.yml`中的日志级别：
```yaml
logging:
  level:
    com.xinling: DEBUG  # 开发时设置为DEBUG
    org.springframework: INFO
    org.springframework.web: DEBUG
```

## 12. 部署建议

### 12.1 生产环境部署
1. 使用专门的生产服务器
2. 配置反向代理（如Nginx）
3. 设置合适的JVM参数
4. 配置监控和日志收集
5. 实施安全加固措施

### 12.2 Docker部署（可选）
创建`docker-compose.yml`：
```yaml
version: '3.8'
services:
  app:
    image: openjdk:21-jre-slim
    ports:
      - "8080:8080"
    volumes:
      - ./target/xinling-admin-1.0.0.jar:/app/app.jar
    command: java -jar /app/app.jar
    depends_on:
      - redis
      - mysql
  
  redis:
    image: redis:latest
    ports:
      - "6379:6379"
  
  mysql:
    image: mysql:8.0
    ports:
      - "3306:3306"
    environment:
      MYSQL_ROOT_PASSWORD: your_root_password
      MYSQL_DATABASE: xinling
    volumes:
      - mysql_data:/var/lib/mysql

volumes:
  mysql_data:
```
