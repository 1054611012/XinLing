## 💾 存储策略设计

### 策略模式实现

```java
/**
 * 文件存储策略接口
 */
public interface FileStorageStrategy {
    
    /**
     * 上传文件
     */
    String upload(MultipartFile file, String path);
    
    /**
     * 删除文件
     */
    boolean delete(String filePath);
    
    /**
     * 获取文件访问URL
     */
    String getFileUrl(String filePath);
}

/**
 * 本地存储策略
 */
@Component
public class LocalFileStorageStrategy implements FileStorageStrategy {
    
    @Override
    public String upload(MultipartFile file, String path) {
        // 使用现有的 FileUploadUtils.upload() 方法
        String filePath = FileUploadUtils.upload(XinLingConfig.getUploadPath(), file);
        return filePath;
    }
    
    @Override
    public boolean delete(String filePath) {
        return FileUtils.deleteFile(XinLingConfig.getProfile() + filePath);
    }
    
    @Override
    public String getFileUrl(String filePath) {
        return filePath; // 本地文件直接返回路径
    }
}

/**
 * 阿里云OSS存储策略
 */
@Component
@ConditionalOnProperty(name = "file.storage.type", havingValue = "aliyun-oss")
public class AliyunOssStorageStrategy implements FileStorageStrategy {
    
    @Autowired
    private FileStorageConfigMapper configMapper;
    
    @Override
    public String upload(MultipartFile file, String path) {
        FileStorageConfig config = configMapper.selectMasterConfig();
        
        OSS ossClient = new OSSClientBuilder()
            .build(config.getEndpoint(), config.getAccessKeyId(), config.getAccessKeySecret());
        
        String objectKey = config.getBasePath() + path;
        
        try {
            ossClient.putObject(config.getBucketName(), objectKey, file.getInputStream());
            return getFileUrl(objectKey);
        } finally {
            ossClient.shutdown();
        }
    }
    
    @Override
    public String getFileUrl(String objectKey) {
        FileStorageConfig config = configMapper.selectMasterConfig();
        String domain = config.getCustomDomain() != null 
            ? config.getCustomDomain() 
            : String.format("https://%s.%s", config.getBucketName(), config.getEndpoint());
        return domain + "/" + objectKey;
    }
}
```

## 🎯 核心业务逻辑

### 文件上传流程

```java
@Service
public class FileRecordServiceImpl {
    
    @Autowired
    private FileStorageConfigMapper configMapper;
    
    @Autowired
    private FileRecordMapper fileRecordMapper;
    
    @Autowired
    private Map<String, FileStorageStrategy> strategyMap; // Spring自动注入所有策略
    
    /**
     * 上传文件（核心方法）
     */
    @Transactional
    public FileRecord uploadFile(MultipartFile file, String businessType, Long businessId) {
        // 1. 获取主配置
        FileStorageConfig config = configMapper.selectMasterConfig();
        if (config == null) {
            throw new ServiceException("未配置存储策略");
        }
        
        // 2. 验证文件
        validateFile(file, config);
        
        // 3. 选择存储策略
        FileStorageStrategy strategy = strategyMap.get(config.getStorageType() + "Strategy");
        if (strategy == null) {
            throw new ServiceException("不支持的存储类型: " + config.getStorageType());
        }
        
        // 4. 生成文件路径
        String fileName = file.getOriginalFilename();
        String extension = FilenameUtils.getExtension(fileName);
        String path = DateUtils.datePath() + "/" + IdUtils.fastSimpleUUID() + "." + extension;
        
        // 5. 上传文件
        String fileUrl = strategy.upload(file, path);
        
        // 6. 计算文件哈希
        String fileHash = calculateHash(file);
        
        // 7. 保存文件记录
        FileRecord record = new FileRecord();
        record.setConfigId(config.getId());
        record.setFileName(fileName);
        record.setFilePath(path);
        record.setFileUrl(fileUrl);
        record.setFileSize(file.getSize());
        record.setFileType(file.getContentType());
        record.setFileExtension(extension);
        record.setFileHash(fileHash);
        record.setStorageType(config.getStorageType());
        record.setBucketName(config.getBucketName());
        record.setObjectKey(path);
        record.setBusinessType(businessType);
        record.setBusinessId(businessId);
        record.setUploaderId(SecurityUtils.getUserId());
        record.setUploaderName(SecurityUtils.getUsername());
        record.setUploaderIp(IpUtils.getIpAddr());
        
        fileRecordMapper.insertFileRecord(record);
        
        return record;
    }
    
    /**
     * 验证文件
     */
    private void validateFile(MultipartFile file, FileStorageConfig config) {
        // 检查文件大小
        if (file.getSize() > config.getMaxFileSize()) {
            throw new ServiceException("文件大小超过限制: " + config.getMaxFileSize() + " 字节");
        }
        
        // 检查文件扩展名
        String extension = FilenameUtils.getExtension(file.getOriginalFilename());
        String[] allowedExts = config.getAllowedExtensions().split(",");
        if (!ArrayUtils.contains(allowedExts, extension.toLowerCase())) {
            throw new ServiceException("不支持的文件类型: " + extension);
        }
    }
    
    /**
     * 计算文件哈希
     */
    private String calculateHash(MultipartFile file) {
        try {
            MessageDigest md = MessageDigest.getInstance("MD5");
            byte[] digest = md.digest(file.getBytes());
            return Hex.encodeHexString(digest);
        } catch (Exception e) {
            return null;
        }
    }
}
```

## 🛠️ 常见问题

### Q1: 如何切换存储平台？

**A**: 在"存储配置"页面设置主配置即可，系统会自动使用主配置上传文件。

### Q2: 如何迁移已有文件到新存储平台？

**A**: 
1. 新增目标存储配置
2. 使用迁移工具批量下载旧文件并上传到新平台
3. 更新文件记录表的 `file_url` 和 `storage_type`

### Q3: 如何实现大文件分片上传？

**A**: 
1. 前端将文件分片（如：每片5MB）
2. 调用 `/file/chunk/upload` 逐片上传
3. 所有分片上传完成后调用 `/file/chunk/merge` 合并

### Q4: 如何设置文件过期时间？

**A**: 在上传时设置 `expireTime` 字段，定时任务自动清理过期文件。

### Q5: 如何统计存储使用量？

**A**: 
```sql
SELECT 
    storage_type,
    COUNT(*) as file_count,
    SUM(file_size) / 1024 / 1024 as total_size_mb
FROM sys_file_record
WHERE status = '0'
GROUP BY storage_type;
```
