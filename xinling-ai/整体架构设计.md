# XinLing AI 模块整体架构设计

## 1. 系统概述

XinLing AI 模块是一个基于 LangChain4j、RAG（检索增强生成）和 Ollama 技术栈的AI能力中心，提供流式对话、知识库问答、NL2SQL等核心功能。

## 3. 核心组件设计

### 3.1 配置组件
- **AiConfigProperties**: AI相关配置属性
- **Langchain4jConfig**: LangChain4j框架配置
- **AiInitializationConfig**: AI模块初始化配置

### 3.2 服务组件
- **OllamaService**: Ollama模型调用服务（支持同步/流式）
- **XinLingAiService**: 主AI服务（RAG增强、多轮对话）
- **DatabaseRagService**: 数据库RAG服务
- **DocumentLoaderService**: 文档加载服务
- **RagExecutor**: RAG执行器（多场景处理）

### 3.3 数据传输对象
- **ChatRequest**: 聊天请求对象
- **ChatResponse**: 聊天响应对象（支持流式）

### 3.4 控制器组件
- **AiController**: 基础AI控制器
- **EnhancedAiController**: 增强版AI控制器

## 4. 关键功能实现

### 4.1 流式对话实现
```java
// 使用Project Reactor实现响应式流
Flux<ChatResponse> streamRagChat(ChatRequest request) {
    return ollamaService.streamChat(augmentedMessage)
        .map(content -> ChatResponse.of(content, request.getSessionId()))
        .concatWith(Flux.just(ChatResponse.finish(request.getSessionId())));
}
```

### 4.2 RAG检索增强
```java
// 检索相关文档片段并增强提示词
List<TextSegment> relevantSegments = contentRetriever.retrieve(request.getPrompt());
String augmentedMessage = "基于以下信息回答问题：\n" + 
    segments + "\n\n问题：" + request.getPrompt();
```

## 5. 数据流设计

### 5.1 标准聊天流程
```
用户输入 → 内容检索 → 提示词增强 → 模型调用 → 响应返回
```

### 5.2 流式聊天流程
```
用户输入 → 内容检索 → 提示词增强 → 流式模型调用 → 逐token返回 → SSE传输
```

### 5.3 NL2SQL流程
```
自然语言查询 → 数据库文档检索 → SQL生成 → 查询执行
```
