## 系统概述

企业级AI管理系统提供了完整的AI模型管理功能，支持：
- 多模型提供商管理（本地Ollama、云端OpenAI/阿里云/智谱AI）
- 模型配置管理（对话模型、嵌入模型）
- 会话配置管理（RAG参数、系统提示词等）
- 运行时动态切换模型

---

## 技术栈要求

- **框架**: Vue 3 + Element Plus（基于若依框架）
- **HTTP客户端**: Axios
- **路由**: Vue Router
- **状态管理**: Pinia/Vuex
- **权限控制**: 基于角色的权限管理（RBAC）

## API接口文档

### 基础信息

- **Base URL**: `/ai`
- **认证方式**: Token (通过请求头 `Authorization: Bearer {token}`)
- **响应格式**: JSON

### 通用响应格式

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

### 1. 模型提供商管理

**接口前缀**: `/ai/provider`

#### 1.1 查询提供商列表

```http
GET /ai/provider/list
```

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| pageNum | Integer | 否 | 页码，默认1 |
| pageSize | Integer | 否 | 每页数量，默认10 |
| providerName | String | 否 | 提供商名称（模糊查询） |
| providerCode | String | 否 | 提供商编码 |
| providerType | String | 否 | 提供商类型：local/cloud |
| status | String | 否 | 状态：0正常/1停用 |

**响应示例**:

```json
{
  "code": 200,
  "msg": "查询成功",
  "rows": [
    {
      "providerId": 1,
      "providerName": "Ollama本地服务",
      "providerCode": "ollama",
      "providerType": "local",
      "apiBaseUrl": "http://localhost:11434",
      "sortOrder": 1,
      "status": "0",
      "remark": "本地部署的开源模型"
    }
  ],
  "total": 4
}
```

#### 1.2 获取提供商详情

```http
GET /ai/provider/{providerId}
```

#### 1.3 新增提供商

```http
POST /ai/provider
Content-Type: application/json

{
  "providerName": "阿里云百炼",
  "providerCode": "aliyun-bailian",
  "providerType": "cloud",
  "apiBaseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
  "sortOrder": 2,
  "status": "0",
  "remark": "阿里云通义千问系列"
}
```

#### 1.4 修改提供商

```http
PUT /ai/provider
Content-Type: application/json

{
  "providerId": 2,
  "providerName": "阿里云百炼（更新）",
  "providerCode": "aliyun-bailian",
  "providerType": "cloud",
  "apiBaseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
  "sortOrder": 2,
  "status": "0",
  "remark": "阿里云通义千问系列"
}
```

#### 1.5 删除提供商

```http
DELETE /ai/provider/{providerIds}
```

**路径参数**: providerIds - 逗号分隔的ID列表，如 `1,2,3`

#### 1.6 导出提供商数据

```http
POST /ai/provider/export
Content-Type: application/json

{
  "providerName": "",
  "providerType": ""
}
```

#### 1.7 获取启用的提供商

```http
GET /ai/provider/enabled
```

**响应示例**:

```json
{
  "code": 200,
  "msg": "查询成功",
  "data": [
    {
      "providerId": 1,
      "providerName": "Ollama本地服务",
      "providerCode": "ollama",
      "providerType": "local",
      "apiBaseUrl": "http://localhost:11434"
    }
  ]
}
```

### 4. AI模型运行时管理

**接口前缀**: `/ai/management`

#### 4.1 切换到指定模型

```http
PUT /ai/management/switchModel/{modelId}
```

**响应示例**:

```json
{
  "code": 200,
  "msg": "模型切换成功"
}
```

#### 4.2 切换到指定会话配置

```http
PUT /ai/management/switchSession/{configId}
```

#### 4.3 使用默认配置

```http
PUT /ai/management/useDefault
```

#### 4.4 刷新所有模型缓存

```http
POST /ai/management/refresh
```

**说明**: 当修改模型配置后，需要刷新缓存才能生效

#### 4.5 获取当前使用的模型

```http
GET /ai/management/currentModel
```

  return request({
    url: '/ai/provider',

    embeddingModels.value = res.data

    if (defaultModel) {
      currentEmbeddingModel.value = defaultModel.modelId
    }
  })
}

function loadSessionConfigs() {
  listSession({ pageNum: 1, pageSize: 100 }).then(res => {
    sessionConfigs.value = res.rows

    if (defaultConfig) {
      currentSessionConfig.value = defaultConfig.configId
    }
  })
}

## 常见问题

### Q1: 如何处理API密钥的输入？

**A**: API密钥字段建议使用密码输入框，并支持显示/隐藏切换：

```vue
<el-form-item label="API密钥">
  <el-input
    v-model="form.apiKey"
    type="password"
    show-password
    placeholder="请输入API密钥"
  />
</el-form-item>
```

### Q2: 如何实现模型类型的联动？

**A**: 根据提供商类型动态显示/隐藏字段：

```vue
<el-form-item 
  label="API密钥" 
  v-if="form.providerType === 'cloud'"
>
  <el-input v-model="form.apiKey" />
</el-form-item>
```

### Q3: 如何处理数字类型字段？

**A**: 使用 `el-input-number` 组件，并设置合理的范围：

```vue
<el-form-item label="温度参数">
  <el-input-number
    v-model="form.temperature"
    :min="0"
    :max="2"
    :step="0.1"
    :precision="2"
  />
</el-form-item>
```

### Q4: 如何实现默认模型的切换逻辑？

**A**: 设置默认模型时，后端会自动取消同类型其他模型的默认状态，前端只需刷新列表：

```javascript
function handleSetDefault(row) {
  proxy.$modal.confirm(`确认将"${row.modelName}"设为默认模型？`).then(() => {
    return setDefaultModel(row.modelId)
  }).then(() => {
    proxy.$modal.msgSuccess('设置成功')
    getList() // 刷新列表
  })
}
```

### Q5: 如何处理关联数据的选择？

**A**: 在选择模型时，需要先加载可用的模型列表：

```javascript
// 加载对话模型列表
function loadChatModels() {
  getChatModels().then(res => {
    chatModelOptions.value = res.data
  })
}

// 加载嵌入模型列表
function loadEmbeddingModels() {
  getEmbeddingModels().then(res => {
    embeddingModelOptions.value = res.data
  })
}
```

### Q6: 导出功能如何实现？

**A**: 使用若依框架提供的导出方法：

```javascript
function handleExport() {
  proxy.download('ai/model/export', {
    ...queryParams.value
  }, `model_${new Date().getTime()}.xlsx`)
}
```

### Q7: 如何实现批量删除？

**A**: 使用表格的多选功能和批量删除接口：

- **文件命名**: 小驼峰，如 `aiModelConfig.js`
